📦 송장 순서로 정리하면
· 엑셀을 내려받을 때 주문정리 · 수령인별 줄 순서가 바뀌어요. 송장이 이 순서로 뽑혀요.
· 같은 품목끼리 모여요. 품목 순서는 집계 칸 순서를 따라요 (식용꽃 → 허브 잎 → 생잎 …).
· 여러 품목이 섞인 주문은 그 묶음 맨 앞에 와요. 어느 묶음으로 갈지는 이 순서로 정해요.
  ① 식용꽃이 하나라도 있으면 → 식용꽃 묶음 (예: 혼합 + 자스민 + 애플 → 혼합)
  ② 자스민이 있으면 → 자스민 묶음 (예: 자스민 + 로즈마리 → 자스민)
  ③ 생잎끼리만 섞이면 → 생잎 섞임 묶음 하나로, 합친 무게가 큰 것부터 (예: 30g × 4 = 120g → 50g → 20g)
  ④ 나머지는 주문이 가장 많은 품목 묶음 (예: 로즈마리 + 타임 → 로즈마리)
· 섞인 주문끼리는 품목 많은 것부터, 단품은 큰 옵션 → 작은 옵션, 같은 옵션은 수량 많은 것부터예요.
  예: 로즈마리 100g → 로즈마리 30g / 자스민 2개 → 자스민 1개
· ★단단 로즈마리처럼 ★ 붙은 품목은 원래 품목(로즈마리) 묶음에 들어가고, 같은 옵션이면 ★가 먼저예요.
· 한 주문의 여러 줄은 항상 붙어 있어요. 화면 · 집계 · 재고는 그대로예요.
· 켜고 끄는 버튼 없이 늘 이 순서로 내려받아요.
